Uit de tabel blijkt dat…
Из таблицы видно, что…
In de grafiek is te zien dat…
На графике видно, что…
Het aantal … is gestegen van … naar …
Количество … выросло с … до …
Het aantal … is gedaald van … naar …
Количество … упало с … до …
Vergeleken met vorig jaar is … hoger / lager.

Meer dan de helft / 60% van de …
Больше половины / 60% …
Таблица к письму не прикладывается. Называй конкретные цифры и даты: не «het is slechter geworden», а «van 5 naar 18 keer». 1–2 цифры достаточно — главное, чтобы были все пункты задания.

Omdat vs. want vs. daarom
omdat, want en daarom — het verschil
▼
OMDAT → bijzin → werkwoord achteraan: "Ik kan niet komen, omdat ik ziek ben." "Ik schrijf u, omdat ik een probleem heb." WANT → hoofdzin → werkwoord op normale plek: "Ik kan niet komen, want ik ben ziek." "Dit is vervelend, want ik moet morgen werken." DAAROM → inversie: "Ik was ziek. Daarom kon ik niet komen." DUS → allebei goed: "Ik was ziek, dus ik kon niet komen." "Ik was ziek, dus kon ik niet komen."

Geachte stagebegeleider, Ik schrijf dit verslag omdat ik een dag stage heb gelopen bij bakkerij Brood & Meer. Tijdens de stagedag heb ik verschillende taken uitgevoerd. Om 8:00 uur heb ik nieuwe broodjes gebakken. Daarna heb ik om 10:00 uur vers brood in zakken gelegd en klaargemaakt voor de klanten. Om 12:00 uur heb ik een nieuw recept samen met de bakker uitgeprobeerd. Vervolgens heb ik om 14:00 uur de bakkerij schoongemaakt. Wat ik het leukst vond, was brood bakken omdat ik van brood hou. Dit vond ik erg waardevol. De minst leuke taak was de bakkerij schoonmaken omdat het lichamelijk zwaar was. Ik raad deze stage dan ook aan andere studenten aan omdat ik veel heb geleerd en het een goede ervaring was. Met vriendelijke groet,

Важно: Опиши каждую картинку с точным временем «Om [tijd] heb ik…». Используй perfectum (heb + voltooid deelwoord). Для leukste и minst leuke обязательно добавь «omdat». В конце чётко скажи, рекомендуешь ли стажировку. Вариант из экзамена 2024: стажировка ещё идёт и текст для новых студентов — тогда пиши в настоящем времени («Om 8 uur bak ik…») и добавь, где стажировка и сколько она длится.
